## 事实
- 资金 50,000 元；3仓、每仓16,000 元目标；只允许 600*.SH/00*.SZ。
- 单股价格 <80元；总市值人民币100亿至800亿元（包括边界），用 SuperMind `get_fundamentals(query(valuation.symbol, valuation.market_cap).filter(...),date=None)` 获取，不再假定问财候选已满足市值。
- 产业范围收紧：半导体材料、设备；AI服务器电源；电子元器件、PCB。行业概念仅提供线索，必须另有可核实业务证据才允许进入最终可交易池。
- 用户原回撤>=20%、量能收缩、成交额>=2亿及买卖退出条件保持；盘中 low5 时间限制取消。
- 重要限制：行业核验白名单默认空，即候选股票全部禁止买入，以避免未经证实的概念股被当作合格标的。正式启用前需要真实上市公司业务审核及平台回测。
- 已完成 Python 语法检查、5个本地静态回归测试；尚未取得真实SuperMind收益/订单。
- 默认近五日成交额全部>=2亿、过去5日均额<前20日均额70%是当前旧实现的具体阈值，而不是用户最初精确给定的唯一量化方式。
- 本分支为设计与测试记录，原模拟盘不变。不能把语法检查当成策略完成。
