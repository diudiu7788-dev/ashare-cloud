# TECH30 产业扩展研究分支

**不是交易策略更新，不能覆盖已经运行的TECH30。** 实盘/模拟盘保持原代码不动。

## 本次任务
将原来以“先进封装、电子元器件”为主的5条问财来源扩展成15条短问句，以便分别观察半导体、AI设施、电子元件、物理AI硬件的覆盖。

主要方向：
- 半导体材料、设备、先进封装；
- AI服务器、液冷、数据中心电源、UPS、高速铜连接（不是光模块）；
- PCB、覆铜板、被动元件、功率半导体；
- 工业传感器、机器视觉硬件、伺服系统。

## 已知限制
- 当前源码原始TECH30未存于本GitHub仓库，因此这只是**独立候选来源验证文件**，不是已合并的正式TECH30版本。
- 15条问财语句目前均未经SuperMind实际回测。若平台对任一问句报错，需要逐条隔离，不能让问句失败导致真实持仓失去管理。
- 概念标签不能证明存在真实产品收入，更不能证明“行业领先、国产替代、打破垄断”；这些需要上市公司报告和经营证据。允许进入候选观察池不代表允许下单。
- 同一公司会有多个标签。输出分别统计来源、合并去重、半导体/硬件交叉，不用分类数相加冒充总数。
- **不强加行业仓位限制**：用户此前只批准扩展候选来源，未批准“每细分行业最多两笔”的新增规则。
- 原规则不变：市值100亿—800亿、股价<50元、10月以来回撤≥20%、缩量且日成交额≥2亿、三种买点及后续波段卖出机制。此诊断文件不负责计算，也不下单。
- 科技/AI硬件定义仍包含物理AI硬件的真实生产商，排除光模块、算力租赁、纯机器人题材；无法在当前短问句中完全可靠排除，需要二次审核。

## 运行方法
1. 在SuperMind新建**研究用临时策略**，不要编辑正在运行的TECH30。
2. 将 `TECH30_source_probe.py` 代码复制进临时策略，建议只回测1—3个交易日的**每日**频率，无下单行为。
3. 看输出 `TECH30_EXPAND_SOURCE` / `TECH30_EXPAND_SUMMARY`，比较原版来源 counts。
4. 仅在每个产业来源能够检索、真实产业资格能二次核实、原版交易回归通过后，才考虑合并到正式策略。

结果：本次仅提交研究源码，尚无回测来源数量、收益或模拟成交数据。
